전북 교사 캘린더 v5
기존 개인 일정 키 bongseo-personal-v1 유지. 봉서중학교 시간표 키 유지. 다른 학교는 학교 ID별로 분리.
학교 검색: 등록된 학교 검색 + 공식 홈페이지 주소로 전북 중학교 직접 추가. 전체 전북 학교 자동 목록 제공은 아직 미구현.
학교별 학사일정·급식 페이지 경로가 다르면 등록 시 경로 수정 필요. 수집 실패 시 오류 표시.
배포: GitHub의 기존 v4 배포 폴더 내용을 이 ZIP의 파일들로 갱신하거나 새 v5 폴더를 올린 뒤 최상위 netlify.toml base를 해당 폴더로 변경. 배포 전 JSON 개인 일정 백업 권장.

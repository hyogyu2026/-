봉서 캘린더 v4

기존 학사일정 연동, 개인 일정 및 다크모드를 유지하면서 주간 시간표, 날짜별 변경/맞교환, 급식 자동 조회 시범 기능을 추가했습니다.

배포: Netlify GitHub 연동 저장소에 이 폴더의 파일을 업로드하세요. 기존 사이트 주소를 유지하려면 기존 연결된 저장소에 반영해야 합니다. Netlify Drop만으로 서버 함수가 작동하는지 보장되지 않습니다.

시간표는 브라우저 localStorage에 저장됩니다. 기존 개인 일정 데이터는 유지됩니다.

급식 HTML 파서는 실제 운영 홈페이지에서 검증하지 못했습니다. 급식 자동 수집에 실패하면 오류를 표시하고 공식 식단 페이지 링크를 제공합니다.

주의: 기존 JSON 백업은 개인 일정만 포함합니다. 시간표는 별도 localStorage 키를 사용하므로 다른 기기로 자동 이전되지 않습니다.
